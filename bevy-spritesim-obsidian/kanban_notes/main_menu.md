## Main Menu

- Must be displayed at startup, over the map
- Separate state from main game (which is currently the map with Michel)
- Several options
  - New game -> Reset the map
  - Load game -> Inactive for the moment
  - Save game -> Inactive for the moment
  - Quit -> Bye !
- Escape show/hide the Main Menu in game
